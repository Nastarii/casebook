# MVP Priorities

## Primeiro

1. Leitor de projeto com capítulos e páginas.
2. Modelagem persistente de projetos, capítulos, páginas e blocos.
3. Editor mínimo de conteúdo textual.
4. Biblioteca narrativa de projetos.

## Depois

1. Upload de assets.
2. Blocos de imagem e código.
3. Templates editoriais.
4. Autenticação.

## Critério de corte

Se uma funcionalidade não melhora leitura, narrativa ou preservação de conhecimento, ela não pertence ao MVP inicial.
