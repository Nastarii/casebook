# Design System Foundation

Esta fundação define a sensação visual do Casebook antes da criação de componentes.

## Tipografia

- Display: serif editorial para títulos e aberturas de capítulo.
- Body: sans-serif legível para leitura longa.
- Escala: títulos amplos apenas em contextos editoriais; interfaces compactas usam tamanhos contidos.

## Espaçamento

- Base: múltiplos de 4px.
- Ritmo de leitura: espaços generosos entre seções e parágrafos.
- Largura de texto: limitar blocos longos para preservar conforto visual.

## Grid

- Conteúdo centralizado com largura máxima.
- Layouts de leitura priorizam coluna principal e navegação discreta.
- Evitar grades densas que remetam a painéis administrativos.

## Tokens iniciais

- `paper`: fundos claros com textura visual suave.
- `ink`: texto principal e hierarquia.
- `brass`: acentos editoriais.
- `moss`: apoio visual sereno.

## Sombras

Sombras devem sugerir profundidade editorial, não cartões administrativos. Usar com parcimônia.

## Animações

Transições suaves com easing editorial. O movimento deve orientar leitura, não competir com o conteúdo.
