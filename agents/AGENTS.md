# Casebook Agents

Os agentes do Casebook trabalham em sequência para preservar arquitetura, experiência e conhecimento.

## Fluxo

1. Backend Agent.
2. Frontend Agent.
3. Test Agent.
4. Review Agent.
5. Docs Agent.

## Regra central

Toda entrega precisa reforçar a sensação de livro digital interativo. Mudanças que aproximem o produto de um painel administrativo devem ser revisadas pelo Review Agent.
