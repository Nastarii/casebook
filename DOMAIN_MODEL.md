# Domain Model

O domínio inicial representa a estrutura narrativa mínima do Casebook.

## Project

Um projeto é o livro digital principal. Ele agrega capítulos, páginas, assets e templates.

## Chapter

Um capítulo organiza páginas dentro de um arco narrativo. Ele deve ajudar o leitor a entender a progressão do projeto.

## Page

Uma página reúne blocos em uma experiência de leitura contínua.

## Block

Um bloco é a menor unidade editorial de conteúdo.

Tipos iniciais:

- text
- image
- video
- code
- architecture
- timeline
- metrics
- decisions
- gallery
- references
- attachments

## Asset

Um asset representa arquivos usados na narrativa: imagens, vídeos, anexos e materiais de apoio.

## Template

Um template define estruturas narrativas reutilizáveis para novos projetos, capítulos ou páginas.

## User

Um usuário representa autoria, edição e acesso ao conhecimento preservado.
