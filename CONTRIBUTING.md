# Contributing

Toda contribuição deve reforçar a visão de livro digital interativo.

## Antes de implementar

- Leia `PRODUCT_VISION.md`.
- Verifique se a mudança melhora leitura, narrativa ou preservação de conhecimento.
- Evite criar interfaces administrativas quando uma apresentação editorial resolver melhor o problema.

## Qualidade

- Código pequeno e tipado.
- Responsabilidades separadas.
- Testes proporcionais ao risco da mudança.
- Documentação quando houver decisão relevante.

## Fluxo sugerido

1. Backend Agent.
2. Frontend Agent.
3. Test Agent.
4. Review Agent.
5. Docs Agent.

Nenhuma entrega deve ser considerada concluída sem revisão da experiência e da arquitetura.
